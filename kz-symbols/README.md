# kz-symbols — reusable state symbols block (KZ/RU)
Copy this folder into a site, then:
  <link rel="stylesheet" href="kz-symbols/kz-symbols.css">
  <div id="kzsym"></div>
  <script src="kz-symbols/kz-symbols.js"></script>
  KZSymbols.render(document.getElementById('kzsym'), isRu, 'kz-symbols/');   // call again on language switch
Anthem text = adilet.zan.kz Z070000258_, annex 3 (unchanged since 2006), checked 30.10.2026.
Flag/emblem SVGs: Wikimedia Commons Flag_of_Kazakhstan.svg, Emblem_of_Kazakhstan_latin.svg (2018 Latin «Qazaqstan» edition).
